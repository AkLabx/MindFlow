# MindFlow v1.0 Active Roadmap & Milestone Blueprint (v1.0_blueprint.md)

This blueprint breaks down Generation 1 (v1.0.x) into 10 concrete milestone increments. Every fresh chat session aligns with an active milestone and updates the milestone status upon completion.

---

## 🗺️ 10-Step Milestone Execution Ledger

- [x] **Milestone 1: Exam-First Canonical Architecture & Context Preservation**
  - **Version Range:** `v1.0.310` – `v1.0.320`
  - **Delivered:** Canonical exam registry in `src/constants/exams.ts`, eliminating 2,512 database alias discrepancies (`CGL PRE` $\rightarrow$ `SSC CGL`). Preserved exam context across all downstream screens.

- [x] **Milestone 2: Offline-First Dexie IndexedDB & Resilient Storage**
  - **Version Range:** `v1.0.320` – `v1.0.330`
  - **Delivered:** IndexedDB offline-first architecture with Dexie. Instant 0ms local hydration; network as background delta synchronization. Upsert-safe mutations.

- [x] **Milestone 3: Unified Guest Auth Portal & Option B Startup Lifecycle**
  - **Version Range:** `v1.0.330` – `v1.0.340`
  - **Delivered:** Clean separation of app launch lifecycle (`IntroEngine` instant render + background `useAppBootstrap`). Preserved OAuth token hash extraction before HashRouter mount. Banned guest login.

- [x] **Milestone 4: Google Chrome Modern Web Guidance (MWG) & INP Scheduling**
  - **Version Range:** `v1.0.340` – `v1.0.345`
  - **Delivered:** Adoption of native HTML `<dialog>`, Popover API with `@starting-style`, CSS Anchor Positioning, and `scheduler.yield()` chunking to maintain 60fps frame budgets ($<16\text{ms}$).

- [x] **Milestone 5: Native Android APK Feel & Mobile-First Gesture System**
  - **Version Range:** `v1.0.345` – `v1.0.355`
  - **Delivered:** Native Android ergonomics across all screens: tactile touch ripples/scaling (`active:scale-95`), zero web bounce, native bottom sheets, and visual viewport keyboard avoidance (`KeyboardAwareBottomBar`).

- [x] **Milestone 6: Deterministic Multi-Slot Development Matrix & Git Protocol**
  - **Version Range:** `v1.0.355` – `v1.0.360`
  - **Delivered:** 3-Slot isolation system (Slot 1 port 3000 on `main`, Slot 2 port 3001, Slot 3 port 3002). Instant Vite HMR live preview without committing. PowerShell runner workaround (`powershell.bat`).

- [x] **Milestone 7: Social Chatroom Brand Realignment & Robust Messaging Ergonomics**
  - **Version Range:** `v1.0.360` – `v1.0.365`
  - **Delivered:** Full UI reskin from WhatsApp clone to MindFlow Indigo/Violet cyber-glassmorphism. New conversation discovery sheet, 450ms long-press, direction-locked swipe-to-reply ($|\Delta Y| > |\Delta X|$), MediaRecorder WebM duration fix, and lightbox fetch-to-blob downloads.

- [x] **Milestone 8: Autonomous 1-Chat = 1-Version Workflow & Closed-Loop Memory Engine**

  - **Delivered:**
