## 2. Generation Vision & Scope Boundaries

- **Core Theme:** Stick strictly to MindFlow's **existing Admin Panel (Mock Tests CMS & Operations)** and **Student Prepared Mock Tests** feature — making it **100% bug-free, fast, native-grade UI/UX, and secure/safe**, with a **dedicated student page for prepared BPSC mock tests** fully controlled (create, edit, update, publish, inspect) from the Admin Panel.
- **Entry Prerequisites:**
  - Verified baseline `v1.0.366` on clean `main` (`94bc143b`), 0 TypeScript errors, clean Vite build.
  - Existing tables `exam_categories`, `test_series`, `tests`, `user_test_attempts` (`20260705000000_create_mock_tests_system.sql`) and RBAC `public.is_admin()`.
- **Exit / Graduation Criteria (`v1.0.380`):**
  - Admins can reliably create, edit, update, clone, schedule, publish/unpublish, and safely delete BPSC mock tests & series from `/admin/test-series` with zero broken forms or slow queries.
  - BPSC aspirants have a dedicated, fast, offline-resilient page listing all admin-prepared BPSC mock tests and can launch, complete, score, review, and resume real timed tests end-to-end.
  - Zero RLS leaks on `user_test_attempts`, zero `navigate(-1)`/`alert()` violations, passing automated tests, and verified desktop + Android WebView UX.
- **Strictly Deferred / Parked Scope (Do NOT Pull Into Gen 1B):**
  - Community Chatroom voice waveform / offline queue / unread badges (parked for Gen 2).
  - Gemini Live Voice Coach `AudioWorklet` / controls (parked for Gen 2).
  - Daily Mission page, multiplayer quiz battles, voice lounges, and institutional billing (parked).
  - Any brand-new unrelated features outside Admin Panel + Prepared Mock Tests (BPSC).
- **Guardrail & Invariant Focus:**
  - `DEC-0001` (Canonical `BPSC` exam aliases from `examRegistry.ts`), `DEC-0002` (Logical Back), `DEC-0004` (0ms Offline-First), `DEC-0007` (MWG `<dialog>`/`<16ms` INP), `DEC-0008` (44x44px touch targets & Android feel), and strict `<=10 files` per version Circuit Breaker.
