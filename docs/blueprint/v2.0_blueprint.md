## 2. Generation Vision & Scope Boundaries

- **Core Theme:** Harden MindFlow's existing **Community Chatrooms & Study Rooms (`src/features/community/`)** end-to-end — resolving Supabase Advisor RLS/FK lints, making Realtime v2 channels, offline text/voice outbox sync, WebM voice note recording/playback, Android keyboard/swipe ergonomics, native `<dialog>` moderation menus, media compression/lightboxes, and community feeds fast, bug-free, native-grade, and secure.
- **Entry Prerequisites:**
  - Verified baseline `v1.0.380` on clean `main` (`Gen 1B` graduated `COMPLETED`), `0` TypeScript errors, `43/43` Vitest (`275/275`), clean `vite build`, and `1/1` Playwright E2E smoke test.
  - Documented non-blocking Supabase Advisor backlog carried over from `v1.0.380` (`chat_room_messages` / `chat_message_reactions` `auth_rls_initplan` and 2 unindexed FKs: `chat_message_reactions_user_id_fkey`, `chat_room_messages_reply_to_id_fkey`).
- **Exit / Graduation Criteria (`v1.0.390`):**
  - Zero `auth_rls_initplan` or unindexed FK advisor warnings on `chat_room_messages` and `chat_message_reactions`, with resilient Realtime v2 reconnects and clean channel cleanup.
  - Zero-latency (`0ms`) local room & message hydration via IndexedDB with idempotent offline text/voice note queuing and reliable WebM duration/waveform playback.
  - Native Android WebView chat UX (`>=44x44px` `type="button"` `active:scale-95` controls, `<KeyboardAwareBottomBar>`, 2D swipe-to-reply axis locking, native `<dialog>` menus/lightboxes) verified via Vitest, Playwright E2E, and Chrome DevTools MCP (`0` console errors).
- **Strictly Deferred / Parked Scope (Do NOT Pull Into This Generation):**
  - Gemini Live Voice Coach `AudioWorklet` enhancements (parked for next generation).
  - Net-new social/billing features (peer live quiz battles, paid study groups, institutional rooms — parked for Gen 3).
  - Refactoring unrelated `src/features/mock-tests/` or `src/features/admin/` modules beyond preserving Gen 1B invariants.
- **Guardrail & Invariant Focus:**
  - `DEC-0002` (Logical Back), `DEC-0004` (0ms Offline-First Dexie), `DEC-0007` (MWG `<dialog>` / `<16ms` INP), `DEC-0008` (Native Android Feel & `>=44x44px` Touch Targets), `DEC-0011` (MindFlow Indigo/Violet Messenger Theme), `DEC-0012` (2D Axis-Locked Swipe, Dynamic Visual Viewport, WebM Duration & Fetch-to-Blob Lightbox), and Circuit Breakers (`<= 10` files/version, explicit confirmation before SQL DDL migrations).
