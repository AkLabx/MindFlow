## 4. Engineering Decisions (Path A vs Path B)

### Decision 1: 3-Tier Monotonic Continue Learning Reconciler, Best-Attempt Series Analytics & Container-Query `<TestLeaderboardCard />`
- **Context & Problem Statement**: Static placeholders in `ExamCategoriesPage.tsx` and `TestsListPage.tsx` masked real student engagement. The platform required an offline-first mechanism to surface active and recently completed mock test attempts, compute aggregate series stats, and render ranked leaderboards across varying viewport widths (from a 320px sidebar card to full-screen desktop). Furthermore, resuming tests risked race conditions with previously completed attempts.
- **Path A (Alternative Considered)**:
  - Naively fetch all attempt records from Supabase on mount without caching.
  - Render a standard responsive HTML table for the leaderboard relying on horizontal scroll.
  - Compute series progress using the latest attempt only.
  - *Why Rejected*: Uncached queries create slow spinners on spotty mobile networks; wide tables horizontally scroll awkwardly in narrow 320px sidebar columns; latest-attempt progress penalizes students trying re-attempts for practice.
- **Path B (Path Chosen)**:
  - 3-tier Memory $\rightarrow$ `localStorage` $\rightarrow$ IndexedDB (`MindFlowDB.sync_metadata`) 0ms hydration with background reconciliation.
  - Deduplicate Continue Learning items to 1 card per `testId`, sorting active `in_progress` ahead of `completed`, while strictly stripping `answers` JSONB before caching (`DEC-0017`).
  - Guard against completed-attempt resurrection by verifying completion status before reusing cached active sessions, and scoping remote updates to `.eq('status', 'in_progress')`.
  - Compute series stats using each test's best completed attempt for score and accuracy, while summing total time spent across all attempts (`computeSeriesProgressStats`).
  - Adapt `<TestLeaderboardCard />` using CSS Container Queries (`@container leaderboard (inline-size >= 520px)`) to seamlessly switch between table view and stacked card tiles.
- **Do-Not-Break Invariant**: Never persist `answers` JSONB in client attempt caches; never resurrect or mutate a `completed` attempt back to `in_progress`; adapt leaderboard UI via container queries rather than window viewport queries.
- **Decision ID Registered in Ledger**: `DEC-0023`

## 5. Runtime Bugs Caught & Fixes During Development

| Bug / Edge Case Caught | Root Cause | Failure Manifestation | Surgical Remedy Applied |
| :--- | :--- | :--- | :--- |
| **Completed-Attempt Overwrite on Re-attempt** | Stale local `active_test_session` snapshot retained the ID of a completed attempt (`ff1a73ce-eb10...`). When the student started a re-attempt, `startOrResumePreparedMockAttempt` reused the completed attempt ID instead of creating a fresh attempt. | The previous completed attempt was resurrected and demoted back to `in_progress`, overwriting the student's completed score. | Added `isTestAttemptLocallyCompleted()` guards in `getCachedActivePreparedMockAttempt`, `readActivePreparedMockAttemptIndexedDB`, and `startOrResumePreparedMockAttempt`, and added `.eq('status', 'in_progress')` to remote Supabase updates in `savePreparedMockAttemptProgress`. Verified re-attempts spawn fresh attempts cleanly. |
| **Leaderboard Table Overflow in Narrow 320px Sidebar** | Standard 5-column table was wider than the right-hand sidebar container on `TestsListPage.tsx` at intermediate widths. | Table columns clipped or caused unwanted inner scrollbars on screens between 768px and 1024px. | Added CSS Container Queries (`container-type: inline-size; container-name: leaderboard`) with `@container leaderboard (inline-size >= 520px)` to render a rich table only when wide enough, smoothly rendering stacked touch cards otherwise. |
| **External CSP & Offline Dependency** | `ExamCategoriesPage.tsx` referenced `url('https://grainy-gradients.vercel.app/noise.svg')` in inline styles. | Triggered unnecessary third-party network request on mount and broke offline rendering when cached assets expired. | Removed external noise SVG url and replaced with clean Tailwind gradient background (`OLD-014`). |
