## 2. Executive Summary
Eliminated the `QuestionBuilder` UUID refetch loop, render-phase `setState` warning, and PostgREST 1,000-row unpaged filter-options bottleneck while adding **Canonical Exam Group Filtering** (`canonical:bpsc` resolving all 20 BPSC aliases including `BPSC TRE3`). Standardized all 62 builder buttons onto explicit `type="button"`, upgraded mobile ergonomics (`< lg` CSS-preserved 2-tab switcher and `>=44x44px` always-visible touch controls), and switched notifications onto MindFlow's Top-Layer Popover `useNotification()` store.

## 4. Engineering Decisions (Path A vs Path B)

### Decision 1: SWR `get_distinct_values` RPC Filter Cache + Canonical Alias Resolution vs Unpaged Client Scan
- **Context & Problem Statement**: `fetchFilterOptions()` previously ran an unpaged `.from('questions').select('subject, difficulty, examName, examYear, topic')`, which PostgREST silently capped at 1,000 rows—hiding exam papers, subjects, and topics while downloading unnecessary rows on every mount. Meanwhile, filtering by `BPSC` missed 20+ legacy/TRE paper aliases.
- **Path A (Alternative Considered)**:
  - Description: Paginate through all `questions` rows client-side in 1,000-row batches and build distinct sets in memory, or hardcode a separate `BPSC` list inside `QuestionFilterBar.tsx`.
  - Why Rejected: Multi-page client scans scale linearly with question bank growth (10,000+ rows) and waste mobile bandwidth; duplicating exam aliases outside `examRegistry.ts` violates `DEC-0001`.
- **Path B (Path Chosen)**:
  - Description: Run 5 parallel `supabase.rpc('get_distinct_values', { column_name })` calls cached via 5-minute in-memory TTL + `localStorage` snapshot + offline `db.getQuizMetadataCache()` fallback, and resolve `canonical:<examId>` filters through `resolveCanonicalExamNames()` in `examRegistry.ts`.
  - Why Chosen / Evidence: Instantaneous cached dropdown hydration, zero silent 1,000-row truncation, clean empty-string scrubbing (`Difficulty` shows only `Easy`, `Hard`, `Medium`), and full 5,794-question canonical BPSC coverage.
- **Do-Not-Break Invariant**: Never reintroduce unpaged `.from('questions').select(...)` metadata scans or bypass `resolveCanonicalExamNames()` for canonical exam group filters.
- **Decision ID Registered in Ledger**: `DEC-0015` (`OLD-007`)

### Decision 2: Ref-Deduped Selection Sync + CSS-Preserved `< lg` Mobile Tabs
- **Context & Problem Statement**: Toggling questions in `QuestionBuilder` triggered a full `fetchQuestionsByUUIDs` network request on every echoed `initialQuestionIds` prop update and called `onChange` inside `setSelectedQuestions(prev => ...)`, causing React render-phase warnings. On mobile (`390x844`), side-by-side panes crushed cards and hover-only `opacity-0` delete buttons were invisible.
- **Path A (Alternative Considered)**:
  - Description: Conditionally unmount `QuestionSearchPanel` when switching to the `Selected` mobile tab and keep `useEffect([initialQuestionIds])` refetching from Supabase.
  - Why Rejected: Unmounting `QuestionSearchPanel` wipes active filters, loaded results, and scroll position on every tab switch; refetching UUIDs per click wastes bandwidth and causes UI flicker.
- **Path B (Path Chosen)**:
  - Description: Track `selectedQuestionsRef` and `lastSyncedIdsKeyRef` to short-circuit echoed `initialQuestionIds`, move `onChangeRef.current(nextIds)` outside state updaters via `commitSelection()`, preserve both panels in the DOM with `flex` / `hidden lg:flex` behind a `< lg` 2-tab switcher, and make every control `type="button"` with `>=44x44px` touch targets.
  - Why Chosen / Evidence: Verified 0 redundant network refetches across 20 rapid add/remove toggles, 0 React render-phase warnings, preserved `Exam: BPSC (All)` results across mobile tab switches, and `44x44px` verified touch targets.
- **Do-Not-Break Invariant**: Never call `onChange` inside a `setSelectedQuestions` updater function, never unmount `QuestionSearchPanel` on mobile tab change, and never hide `SelectedQuestionsPanel` delete controls behind `opacity-0`.
- **Decision ID Registered in Ledger**: `DEC-0015` (`OLD-007`)

## 5. Runtime Bugs Caught & Fixes During Development

| Bug / Edge Case Caught | Root Cause | Failure Manifestation | Surgical Remedy Applied |
| :--- | :--- | :--- | :--- |
| **Redundant UUID refetch per toggle** | `useEffect` depended on `initialQuestionIds` array reference without deduplicating echoed `onChange` IDs. | Adding/removing a question triggered a full `questions?id=in.(...)` network call every click. | Added `lastSyncedIdsKeyRef` + `selectedQuestionsRef` delta hydration in `QuestionBuilder.tsx`. |
| **Render-phase parent `setState` warning** | `onChange(...)` ran synchronously inside `setSelectedQuestions(prev => ...)` updater callbacks. | React logged `Cannot update a component while rendering a different component`. | Centralized mutations in `commitSelection()` calling `onChangeRef.current(nextIds)` outside any updater. |
| **PostgREST `.or()` 400 on commas/parens** | Raw user search strings with `(`, `)`, or `,` (e.g., `"Article 21(A), Bihar"`) broke PostgREST `.or()` syntax. | Search queries containing punctuation failed with PostgREST 400 syntax errors. | Added `sanitizePostgrestSearch()` stripping `[(),]` and collapsing whitespace before building `.or()`. |
| **Silent 1,000-row cap & blank `""` difficulty** | `fetchFilterOptions()` scanned `.from('questions')` without RPC aggregation or empty-string filtering. | Truncated exam/topic options and rendered an empty `""` `<option>` in Difficulty. | Switched to 5 parallel `get_distinct_values` RPCs with SWR cache and trimmed non-empty filtering. |
| **Unmounted toast & tiny mobile hit targets** | `QuestionBuilder` used `react-hot-toast` (no `<Toaster />` mounted) and `QuestionResultCard` / `SelectedQuestionsPanel` had `<44px` / hover-only buttons. | Bulk Add/Import toasts failed silently; mobile tapping was cramped and delete icons were hidden. | Migrated to `useNotification()` Popover toasts, `< lg` 2-tab switcher, `type="button"`, and `>=44x44px` visible buttons. |
