## 4. Engineering Decisions (Path A vs Path B)
### Decision 1: Hybrid 0ms SWR + Stale-Time Gate & Deterministic Playwright Interception
- **Context & Problem Statement**: Prior caches in `mockTestsApi.ts` stored `fetchedAt` without enforcing stale-times, causing redundant 4-query Supabase bursts on every back-navigation, while `adminTestSeriesApi.ts` had no CMS list cache and lacked cross-feature invalidation into student listings. Additionally, `DEC-0006` prohibits guest login, requiring a deterministic E2E auth/data strategy.
- **Path A (Alternative Considered)**:
  - Description: Always background-refetch on every component mount regardless of `fetchedAt` age, and run Playwright exclusively against live Supabase credentials.
  - Why Rejected: Always re-fetching wastes Supabase egress on rapid tab/back navigation; relying solely on live credentials risks mutating production DB `mock_test_attempts` and breaks offline/CI repeatability.
- **Path B (Path Chosen)**:
  - Description: Hybrid 0ms SWR + Stale-Time Gate (`MOCK_SWR_STALE_TIMES_MS` + `ADMIN_CMS_STALE_TIME_MS`) that serves 0ms cached snapshots (`DEC-0004`), skips redundant network refetches while `age < staleTimeMs`, supports explicit `{ forceRefresh: true }`, purges Admin + Student 3-tier caches and emits `MOCK_CACHE_INVALIDATED_EVENT` on every Admin mutation (protecting `mock_active_attempt_*`), and runs Playwright E2E via deterministic `/auth/v1/*` + `/rest/v1/*` route interception with optional `PLAYWRIGHT_TEST_EMAIL`/`PASSWORD` live override.
  - Why Chosen / Evidence: Cuts redundant network fetches to `0` on fresh revisits (verified in both Playwright E2E and Chrome DevTools MCP), guarantees instant Admin $\rightarrow$ Student cache freshness, and passes E2E reproducibly without leaking secrets or dirtying DB rows.
- **Do-Not-Break Invariant**: All Mock Tests and Admin CMS fetchers must honor `MOCK_SWR_STALE_TIMES_MS` / `ADMIN_CMS_STALE_TIME_MS` and `isTestWithinScheduleWindow()`, Admin mutations must purge student catalog caches via `invalidateAdminCmsCatalogCaches()` without wiping `mock_active_attempt_*`, `syncService.processEventQueue()` must remain promise-coalesced, and `vitest.config.ts` must exclude `**/e2e/**`.
- **Decision ID Registered in Ledger**: `DEC-0027` (`OLD-016` retired)
