## 4. Engineering Decisions (Path A vs Path B)

### Decision 1: Zero-DDL Paginated Client-Side Aggregator vs. New Postgres `SECURITY DEFINER` Analytics RPC
- **Context & Problem Statement**: Admin test insights require aggregating attempt counts, unique student counts, score medians, score bands, and per-question accuracy/skip diagnostics from `mock_test_attempts` (`answers` JSONB) and `questions` without leaking student PII or requiring destructive/blocking database migrations.
- **Path A (Alternative Considered)**:
  - Description: Introduce a new SQL migration adding `public.get_mock_test_analytics(p_test_id uuid)` as a `SECURITY DEFINER` Postgres RPC.
  - Why Rejected: Introduces a database DDL migration and backend deployment dependency for an admin-only view when admins already hold RLS read access to `DB_TABLES.MOCK.ATTEMPTS` and `DB_TABLES.BANK.QUESTIONS`.
- **Path B (Path Chosen)**:
  - Description: Zero-DDL paginated client-side aggregator (`ATTEMPTS_PAGE_SIZE = 500` up to `MAX_ANALYTICS_ATTEMPTS = 5000`) over existing admin RLS on `DB_TABLES.MOCK.ATTEMPTS` + `100`-UUID chunked `DB_TABLES.BANK.QUESTIONS`, guarded by MWG `break-up-long-tasks` `yieldToMain()` (`scheduler.yield()` + `setTimeout` fallback on a 50ms deadline) and strict PII-free 3-tier SWR caching (`Memory` $\rightarrow$ `localStorage` $\rightarrow$ `MindFlowDB.sync_metadata`).
  - Why Chosen / Evidence: Ships cleanly with zero DDL changes, prevents PostgREST URL-length overflow on 150-question mocks via 100-UUID chunking, keeps main-thread INP responsive via 50ms cooperative yielding, and strictly strips `user_id`, `profiles`, and `answers` from DTOs and local caches.
- **Do-Not-Break Invariant**: Never persist `user_id`, `profiles`, or raw `answers` JSONB in admin analytics DTOs or browser caches (`localStorage` / `MindFlowDB.sync_metadata`); paginate `DB_TABLES.MOCK.ATTEMPTS` (`500`/page) and chunk `DB_TABLES.BANK.QUESTIONS` (`100` UUIDs); skip `__cbt_meta`; keep `yieldToMain()` 50ms budget and LIFO `<AdminTestAnalyticsDrawer />` $\rightarrow$ `<QuestionPreviewDrawer />` DOM order.
- **Decision ID Registered in Ledger**: `DEC-0024`

## 5. Runtime Bugs Caught & Fixes During Development

| Bug / Edge Case Caught | Root Cause | Failure Manifestation | Surgical Remedy Applied |
| :--- | :--- | :--- | :--- |
| **`__cbt_meta` Key in `answers` JSONB** | Prepared mock runner persists CBT timer/cursor metadata under `answers.__cbt_meta` (`DEC-0021`). | Naive `Object.keys(answers)` iteration would treat `__cbt_meta` as a question ID and distort attempt/skip totals. | Filtered out `'__cbt_meta'` in both `orderedQuestionIds` deduplication and per-question answer evaluation inside `computeMockTestAnalytics()`. |
| **`passing_marks <= 0` Divide-by-Zero / False Failures** | Tests without a configured pass cutoff store `passing_marks = 0`. | Dividing or evaluating `score >= 0` as a pass cutoff would render misleading pass/fail percentages. | Added `hasPassCutoff = passingMarks > 0`; when `false`, sets `passRatePct = null`, `failedCount = 0`, and renders `"No pass cutoff configured"` pill. |
| **Stale Async Response Race on Rapid Test Switching** | Switching between test cards while an earlier `fetchMockTestAnalytics` request is still in flight. | Slow response from Test A could overwrite Test B's drawer state on late resolution. | Added monotonic `requestSeqRef`, `activeTestIdRef`, and `isMountedRef` checks after every `await` in `AdminTestAnalyticsDrawer.tsx`. |
| **LIFO Top-Layer Dismissal for Nested Preview Drawer** | Opening `QuestionPreviewDrawer` from inside `AdminTestAnalyticsDrawer` creates two stacked `<dialog>` Top-Layer elements. | Incorrect DOM/mount order or shared close handlers could dismiss the parent insights drawer when closing preview. | Rendered `<AdminTestAnalyticsDrawer />` before `<QuestionPreviewDrawer />` in `AdminTestSeriesDashboard.tsx` so `Escape` / Close dismisses preview first (`openDialogs: 2` $\rightarrow$ `1` $\rightarrow$ `0`). |
| **Vertical Touch Scroll vs. Swipe-Right Dismiss** | Mobile vertical scrolling inside the drawer can drift slightly horizontally (`DEC-0012`). | Naive `dx` check would accidentally close the drawer while scrolling question diagnostics. | Implemented 2D axis-locking (`touchStartRef`): locks `'y'` when `|ΔY| > |ΔX|` and dismisses only when locked `'x'` with `ΔX >= 88` and `ΔX > |ΔY| * 1.3`. |
