## 4. Engineering Decisions (Path A vs Path B)
### Decision 1: Paid-App Shell, Dedicated Headers, MWG Scroll-Snap Rails, `PYQ` vs `MOCK` Taxonomy & 6-Domain Exam Grouping
- **Context & Problem Statement**: Sub-pages (`/mcqs/test-series*`, `/quiz/library*`, `/purchased`) stacked local titles under the global header, the primary footer highlighted `School` and `Community` ahead of Mock Tests and Purchased access, vertical card grids stretched long categories on mobile, raw database exam strings split alphabetically `[A-I]/[J-R]/[S-Z]` obscured exam families, and official past papers lacked an explicit `PYQ` vs `Expert Mock` schema/badge distinction.
- **Path A (Alternative Considered)**:
  - Description: Keep global header on all sub-pages with `School`/`Social` in the bottom footer, install a third-party JS carousel/swipe library (`swiper` or `embla-carousel`), keep alphabetical `[A-I]` buckets, and infer `PYQ` solely from series titles on the client.
  - Why Rejected: Wasted vertical mobile viewport on duplicate headers, misprioritized primary navigation ahead of paid mock tests, added JS bundle bloat and gesture conflict instead of native CSS scroll-snap, forced aspirants to hunt across arbitrary alphabet slices, and made `PYQ` classification brittle across Admin CMS and Student filters.
- **Path B (Path Chosen)**:
  - Description: Hide global header on `/mcqs/test-series*`, `/quiz/library*`, and `/purchased` via `isHeaderHiddenRoute` in favor of sticky [`DedicatedPageHeader`](../../src/components/ui/DedicatedPageHeader.tsx); update footer tabs to `Dashboard | Mock Tests | AI | Purchased | Profile` while relocating `School Mode` and `Community & Social` to [`SidePanel`](../../src/layouts/SidePanel.tsx); implement zero-dependency CSS scroll-snap [`SwipeableTabViewport`](../../src/components/ui/SwipeableTabViewport.tsx) + `.mf-h-rail` card rails; ship additive migration `add_question_source_and_mock_types` (`question_source`, `series_type`, `test_type`) with `107` official BPSC/SSC CGL PYQ tests; and replace `[A-I]/[J-R]/[S-Z]` with 6 semantic domains in [`examDomains.ts`](../../src/features/quiz/constants/examDomains.ts).
  - Why Chosen / Evidence: Zero new runtime npm dependencies, clean `0ms` SWR hydration, `0` Supabase security/performance advisor regressions, `46/46` Vitest suites (`292` tests) green, Playwright smoke green, and `0px` overflow / `0` sub-44px targets verified on Desktop + Mobile Chrome DevTools MCP.
- **Do-Not-Break Invariant**: Keep global header hidden on `/mcqs/test-series*`, `/quiz/library*`, and `/purchased` (use `DedicatedPageHeader`); preserve the 5-tab Paid-App footer (`Dashboard | Mock Tests | AI | Purchased | Profile`) and `SidePanel` links for `School Mode`/`Community & Social`; preserve `SwipeableTabViewport` lightweight resting slides and `.mf-h-rail` scroll-snap; maintain `question_source`/`series_type`/`test_type` (`PYQ` vs `MOCK`/`EXPERT`) normalization; and keep semantic domain grouping in `examDomains.ts` (`DEC-0030`, `OLD-019`).
- **Decision IDs Registered in Ledger**: `DEC-0030`, `OLD-019`

## 5. Runtime Bugs Caught & Fixes During Development
| Bug / Edge Case Caught | Root Cause | Failure Manifestation | Surgical Remedy Applied |
| :--- | :--- | :--- | :--- |
