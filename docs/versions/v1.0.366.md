## 4. Engineering Decisions (Path A vs Path B)
### Decision 1: Cold-Start Memory Architecture (Ultra-Lean Hot Context vs Monolithic Memory)
- **Context & Problem Statement**: Incoming AI agents were reading `docs/APP_JOURNEY_LOG.md` (216 KB) on startup, consuming ~70k tokens and causing context degradation and hallucinations.
- **Path A (Monolithic Memory)**: Continue referencing full changelogs and memory contexts on session start.
  - *Why Rejected*: High token cost, slow prompt caching, attention drift, and hallucinations of solved bugs.
- **Path B (Ultra-Lean Hot Context + Handover Baton)**:
  - Establish a strict <20 KB Hot Context layer (`CURRENT_HANDOVER.md`, `DECISIONS_MASTER.md`, `v1.0_blueprint.md`). Shift `APP_JOURNEY_LOG.md` to an on-demand archive updated only during closeout.
  - *Why Chosen*: Fast cold start (~5k tokens), zero context bloat, 100% adherence to active invariants.
- **Do-Not-Break Invariant**: Never load historical dossiers or full changelogs into context on session startup.
- **Decision ID Registered in Ledger**: `DEC-0013`
