## 4. Engineering Decisions (Path A vs Path B)
### Decision 1: Non-Destructive Domain Prefixing (`mock_*` / `quiz_*`) + `src/config/dbTables.ts` Registry While Preserving Local IndexedDB Store Names
- **Context & Problem Statement**:
  - Legacy table names (`tests`, `test_series`, `exam_categories`, `user_test_attempts` vs `saved_quizzes`, `bridge_saved_quiz_questions`, `quiz_history`) scattered across alphabetical lists in Supabase Dashboard, causing confusion between Admin-Prepared Mock Tests and Custom Student Quizzes. Simultaneously, renaming browser IndexedDB stores in `src/lib/db.ts` risked breaking or wiping existing offline user caches.
- **Path A (Alternative Considered)**:
  - Description: Keep legacy SQL table names and add a `type` column, or bump `MindFlowDB` to v16 and rename IndexedDB object stores to match remote SQL names.
  - Why Rejected: A `type` column blurs distinct RLS, marking, and schedule-window contracts; renaming browser IndexedDB object stores risks offline user data migration failures (`DEC-0004`).
- **Path B (Path Chosen)**:
  - Description: Execute non-destructive `ALTER TABLE ... RENAME TO ...` (`mock_*` / `quiz_*`), atomically update all 10 live PostgreSQL functions with strict `search_path` + `REVOKE/GRANT` ACLs, centralize remote identifiers in `src/config/dbTables.ts` (`DB_TABLES` & `DB_RPCS`) with `as const` PostgREST select literals, and keep browser IndexedDB store names unchanged in `src/lib/db.ts`.
  - Why Chosen / Evidence: Zero data loss, all 14 RLS policies and 22 constraints retained automatically, zero stale `pg_proc` references, `0` TypeScript errors, and `34/34` test suites (`214/214` tests) green.
- **Do-Not-Break Invariant**: Always reference Supabase assessment tables and RPCs via `DB_TABLES` / `DB_RPCS` in `src/config/dbTables.ts` (with `as const` on shared PostgREST select constants), never reintroduce raw `.from('exam_categories'|'test_series'|'tests'|'user_test_attempts'|'saved_quizzes'|'bridge_saved_quiz_questions'|'quiz_history')`, and keep local IndexedDB store names (`'saved_quizzes'`, `'quiz_history'`) in `src/lib/db.ts` decoupled and intact (`DEC-0004`).
- **Decision ID Registered in Ledger**: `DEC-0018` (and `OLD-010`)
