## 4. Engineering Decisions (Path A vs Path B)
### Decision 1: Keyed `<ErrorBoundary>` + Inner `<Suspense>` & Scoped Combobox Keyboard Handling in Admin Shell
- **Context & Problem Statement**: Unkeyed error boundaries remain stuck in `hasError: true` across route changes, unnested lazy `<Outlet />` chunks unmount the entire `AdminLayout` during chunk fetches, and `window`-level `Enter` listeners in `AdminCommandPalette` hijack keyboard activation when focus is on the Close button.
- **Path A (Alternative Considered)**:
  - Description: Keep an unkeyed `ErrorBoundary` outside `AdminLayout` and global `window` `Enter` handling in `AdminCommandPalette`.
  - Why Rejected: Crashes in one admin screen would break sidebar navigation out of the broken screen, lazy route chunks would flash full-screen loaders, and keyboard users tabbing to Close (`X`) would accidentally execute a command.
- **Path B (Path Chosen)**:
  - Description: Wrap `<Outlet />` inside `<main>` with `<ErrorBoundary key={`${location.pathname}:${outletResetKey}`}>` + `<Suspense>`, track `[location.pathname, location.search]` for mobile drawer auto-close, flush-size the `NativeDialog` drawer (`w-[min(18.5rem,85vw)]`), and scope `AdminCommandPalette` arrow/Enter handling to the WAI-ARIA `combobox` input while keeping explicit `type="button"` `min-h-[44px]` `active:scale-95` controls throughout.
  - Why Chosen / Evidence: Preserves shell availability during child crashes/chunk loads, allows reload-free recovery, clears error state automatically on sidebar/palette navigation, and passes all 5 shell/RBAC Vitest specs plus Desktop/Mobile Chrome verification with `0px` overflow.
- **Do-Not-Break Invariant**: Always keep `<Outlet />` wrapped in a route-keyed `<ErrorBoundary>` + `<Suspense>` inside `AdminLayout`, close the mobile `NativeDialog` drawer on both `location.pathname` and `location.search` transitions, keep `ADMIN_NAV_GROUPS` synced to `ROUTES`, and preserve `>=44x44px` `type="button"` `active:scale-95` controls with `scroll-mb-28` / `env(safe-area-inset-bottom)` clearance.
- **Decision ID Registered in Ledger**: `DEC-0025` (retiring `OLD-015`).
