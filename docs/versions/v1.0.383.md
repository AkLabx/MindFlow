## 4. Engineering Decisions (Path A vs Path B)
### Decision 1: Course Packaging, Payment Fulfillment & Direct `#/exam/:testId` Entitlement Guard (`DEC-0031`)
- **Context & Problem Statement**: Needed real paid course monetization before live Razorpay merchant onboarding while protecting direct deep-links into `#/exam/:testId`.
- **Path A (Alternative Considered)**: Static client-only tier flags without `user_course_entitlements`, `payments` receipt columns, or Razorpay stubs.
- **Path B (Path Chosen)**: Additive normalized SQL (`profiles.student_id`, `mock_series` pricing/validity/demo/`course_type`, `mock_tests.is_free_demo`/`is_live`, `payments` receipt columns, `user_course_entitlements` RLS, and 4 `SECURITY DEFINER SET search_path = public, pg_temp` RPCs) driving UPI UTR verification + Admin Student-ID fulfillment and pre-question `#/exam/:testId` lock gating.
- **Do-Not-Break Invariant**: Never fetch locked mock test questions before checking `resolveMockTestAccess`; never expose `student_id_seq` or admin RPCs to `anon`.
- **Decision ID Registered in Ledger**: `DEC-0031` (`OLD-020`).

### Decision 2: Root `/mcqs/test-series` Series-Only Horizontal UX & Pluggable CBT Skins (`DEC-0032`)
- **Context & Problem Statement**: `overflow-x-hidden` + `sticky bottom-0` hid BPSC CBT actions on mobile WebView at question top, root filters cluttered series rails, and SSC CGL needed switchable `TCS iON` vs `Eduquity` UIs.
- **Path A (Alternative Considered)**: Duplicate `PreparedMockExamPage.tsx` per exam board or install third-party carousel/CBT packages.
- **Path B (Path Chosen)**: Extract shared `ExamRunnerSkinProps` modular shells (`BpscDefaultExamShell`, `TcsIonExamShell`, `EduquityExamShell`) sharing one monotonic timer, Dexie state, and submission pipeline with `overflow-x-clip` + `fixed bottom-0`, move root `PYQ/Expert` filtering into `TestsListPage`, and dock `My Attempts` + `Live Test` cleanly above `MainLayout`'s AI orb.
- **Do-Not-Break Invariant**: Preserve `overflow-x-clip` + `fixed bottom-0` across CBT shells and `bottom-[calc(5.75rem+env(safe-area-inset-bottom,0px))]` clearance on `test-series-bottom-action-strip`.
- **Decision ID Registered in Ledger**: `DEC-0032` (`OLD-021`).
