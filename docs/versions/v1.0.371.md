## 4. Engineering Decisions (Path A vs Path B)
### Decision 1: Canonical Exam-Aware Listing (`fetchPreparedMockTestsByExam`), 3-Tier `SYNC_METADATA_STORE` Cache, Shared Shortcut Card & `scroll-mb-28` Clearance
- **Context & Problem Statement**:
  - Student Mock Tests discovery lacked a dedicated BPSC route (`/mcqs/test-series/bpsc`), exact string equality missed canonical exam aliases (`"BPSC TRE3"`, `"70th BPSC Prelims"`), cold WebViews needed 0ms hydration without bumping `MindFlowDB` v15, and fixed `MainLayout` bottom tabs (`z-[10000]`) overlapped bottom-positioned CTAs on shorter viewports.
- **Path A (Alternative Considered)**:
  - Description: Query only `mock_categories` matching exact `'BPSC'`, bump `MindFlowDB` to v16 for a dedicated object store, duplicate shortcut JSX across three pages, and rely on default browser `scrollIntoView`.
  - Why Rejected: Exact category matches silently hide valid BPSC series inside broader categories (`"State PSC"`), bumping `DB_VERSION` increases migration surface unnecessarily, duplicated shortcut markup drifts across pages, and default scrolling obscures focused CTAs behind the fixed bottom navigation bar (`WCAG 2.4.11`).
- **Path B (Path Chosen)**:
  - Description: Match categories, series, and tests through shared canonical helpers (`resolveCanonicalExamSlug`, `doesTextMatchCanonicalExam`, `materializePreparedMockTests`) backed by `examRegistry.ts` (`DEC-0001`), store SWR snapshots in `localStorage` + existing `MindFlowDB.sync_metadata` (`DEC-0004`), extract `<PreparedMockTestsShortcutCard />`, and enforce `scroll-mb-28` + `>=44x44px` `type="button"` controls.
  - Why Chosen / Evidence: Zero `DB_VERSION` bump, single-source canonical & schedule-window projection shared across live and cached paths, verified `0` console errors and `0px` horizontal overflow in Chrome on Desktop (`1280x800`) and Mobile (`390x844`).
- **Do-Not-Break Invariant**: Always resolve canonical student mock routes via `getPreparedMockTestsRoute()` (preserving `:examSlug` param tokens unencoded), run `isTestWithinScheduleWindow()` on both cached and network reads (`DEC-0017`), scope attempt caches by `userId`, and maintain `scroll-mb-28` + `>=44x44px` touch targets on student mock-test controls.
- **Decision ID Registered in Ledger**: `DEC-0019`

## 5. Runtime Bugs Caught & Fixes During Development
| Bug / Edge Case Caught | Root Cause | Failure Manifestation | Surgical Remedy Applied |
| :--- | :--- | :--- | :--- |
| Fixed bottom tab bar intercepted `BPSC Mocks` click on `ExamCategoriesPage` | Large Hero vertical margins placed `PreparedMockTestsShortcutCard` at `y=589..633` beneath `MainLayout` fixed bottom nav (`z-[10000]`) at shorter viewport heights | Clicking `BPSC Mocks` tapped the overlapping `Profile` tab (`#/profile`) | Tightened `ExamCategoriesPage` hero spacing (`mb-6 sm:mb-8`) and added `scroll-mb-28` (`WCAG 2.4.11` clearance) on interactive controls in `PreparedMockTestsShortcutCard` and `ExamPreparedMockTestsPage` |
| `:examSlug` route pattern encoding hazard | Applying `encodeURIComponent(':examSlug')` turns `:` into `%3A`, breaking React Router param matching | Dynamic `/mcqs/test-series/exam/ssc_cgl` matching would fail | Guarded `ROUTES.TEST_SERIES.EXAM` with `examSlug.startsWith(':')` so route patterns keep `:examSlug` literal |
| `BPSC` vs `BPSSC` token collision | Prefix/substring matching without word boundaries can confuse Bihar PSC (`BPSC`) with Bihar Police (`BPSSC`) | `BPSSC` series would misclassify under `BPSC` | Used escaped `\b` word-boundary regexes + explicit `/\bbihar\s+psc\b/i` inside `doesTextMatchCanonicalExam` |
| Screen-reader text concatenation & `getByText` ambiguity on card CTAs | Adjacent `<span>` label + count rendered `"Full-Length1"` and disambiguated `<span className="sr-only">` matched `getByText` | Screen readers concatenated words without spacing | Inserted explicit `{' '}` spacing between chip label and count (`"Full-Length 1"`) and verified headings/buttons by ARIA role |
