## 4. Engineering Decisions (Path A vs Path B)
### Decision 1: 3-Tier Single-Test & `userId`-Scoped Attempt/Bookmark Cache, `.maybeSingle()`, Adaptive CTA & Canonical Share Cascade
- **Context & Problem Statement**:
  - `TestDetailPage.tsx` read a non-existent `negative_marks_per_question` column, called `navigate(-1)`, showed a static attempt placeholder, lacked offline caching, triggered HTTP `406` on unavailable tests via `.single()`, overlapped its `<h1>` onto the purple hero gradient, and hung on Windows Desktop `navigator.share`.
- **Path A (Alternative Considered)**:
  - Description: Keep `fetchTestDetails()` network-only with `.single()`, store bookmarks globally without `userId` partitioning, skip offline attempt caching, and always await `navigator.share` on Windows Desktop.
  - Why Rejected: Network-only detail pages fail offline on mobile WebViews; `.single()` emits noisy PostgREST HTTP `406` errors on unpublished tests; unscoped bookmarks leak across accounts; Windows Desktop UWP `navigator.share` stalls before rejecting with `AbortError: "Share failed"`.
- **Path B (Path Chosen)**:
  - Description: Implement 3-tier Memory/`localStorage`/`MindFlowDB.sync_metadata` caching with catalog fallback and `DEC-0017` validation, `.maybeSingle()` test fetches, `userId`-scoped `DB_TABLES.MOCK.ATTEMPTS` history and bookmarks, adaptive primary CTA with `resumeAttemptId`, `resolveTestDetailBackTarget()` + `useHardwareBackButton` alignment, canonical Capacitor Share + instant Windows Desktop clipboard fallback, and `<span aria-hidden="true">` thumbnails.
  - Why Chosen / Evidence: Eliminated HTTP `406` console errors, delivered instant `"Link Copied"` Popover feedback on desktop, fixed `<h1>` banner contrast, and passed `36/36` Vitest files (`227/227` tests) + live Desktop (`1280x800`) and Mobile (`390x844`) Chrome verification with `0` console errors.
- **Do-Not-Break Invariant**: Always read `Number(test.negative_marks ?? 0)`, use `.maybeSingle()` in `fetchTestDetails()`, never select `answers` JSONB in `fetchUserTestAttempts()`, validate `location.state.returnTo` (zero `navigate(-1)`), keep `useNotification()` Popover toasts, and render decorative `BrandedThumbnail` initials as `<span aria-hidden="true">`.
- **Decision ID Registered in Ledger**: `DEC-0020` (plus `OLD-011`).
