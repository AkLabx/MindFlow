# Legacy Landing Page

This folder contains the legacy public marketing Landing Page (`LandingPage.tsx`) previously used at the root route (`/`) of the MindFlow Web App.

## Reason for Archival
The application architecture has been updated to follow a "Single Door" philosophy where the root URL (`/`) serves as a dedicated Authentication Portal (Login / Sign Up) for both the web and native Capacitor apps.

The marketing website will be separated into a completely independent website in the future. This code is preserved here for future reuse when that external marketing website is built.

## Date Archived
Archived during the Architectural Change Request - Convert MindFlow Root URL into the Dedicated Authentication Portal.
